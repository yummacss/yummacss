# @yummacss/cdn

Yumma CSS from a script tag. No build step, no Node.js.

## Usage

```html
<script src="https://unpkg.com/@yummacss/cdn"></script>
<div class="c:indigo fw:500">Hello World</div>
```

Classes are read off the page and their CSS is written into a `<style>` tag, including classes added later.

For build-time output, use the [CLI package](../cli) instead.
