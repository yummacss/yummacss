# yummacss

An atomic CSS framework with abbreviated class names.

## Installation
```bash
npm install yummacss -D
npx yummacss init
```

## Commands

### `init`
Initialize configuration file
```bash
npx yummacss init
```

### `build`
Build styles once
```bash
npx yummacss build
```

### `watch`
Build styles continuously
```bash
npx yummacss watch
```
