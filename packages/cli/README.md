# yummacss

A CLI-first CSS framework for the web with abbreviated styles.

## Installation
```bash
npm install yummacss -D
npx yummacss init
```

## Commands

### `init`
Initialize configuration file
```bash
npx yummacss init
```

### `build`
Build styles once
```bash
npx yummacss build
```

### `watch`
Build styles continuously
```bash
npx yummacss watch
```
