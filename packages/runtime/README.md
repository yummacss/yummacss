# @yummacss/runtime

Zero-config browser runtime for Yumma CSS.

## Usage
```html
<script src="https://unpkg.com/@yummacss/runtime"></script>
<div class="bg-blue p-4 br-2">Hello World</div>
```

For build-time optimization, use the [CLI package](../cli) instead.
