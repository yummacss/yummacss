## Getting started

Yumma CSS API provides access to Yumma CSS utilities through Javascript functions.

### Installing

```bash
npm i @yummacss/api
```

## Documentation

Head over to the [Yumma CSS docs](https://www.yummacss.com/docs/dev-api) to learn more.
