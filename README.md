# Yumma CSS

An atomic CSS framework with abbreviated class names.

---

## Installation

Install `yummacss` as a dev dependency and initialize configuration

```bash
npm install yummacss -D
npx yummacss init
```

## Build

```bash
npx yummacss build
```

## Documentation

Learn more at [yummacss.com](https://yummacss.com)
