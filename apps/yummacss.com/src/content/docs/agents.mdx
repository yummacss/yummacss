## Installing the skill

An agent that loads skills, such as [Claude Code](https://claude.ai/), provides both Yumma CSS and Yumma UI.

```bash
npx skills add yummacss/yummacss
```

## Adding it to a project

Save [agents.md](/agents.md) as the instructions file your agent reads. Most read `AGENTS.md` at the project root.

`>>` & `Add-Content` append, so instructions already in the file stay.

<CodeGroup>
```bash title="macOS & Linux"
curl -s https://www.yummacss.com/agents.md >> AGENTS.md
```

```powershell title="Windows"
irm https://www.yummacss.com/agents.md | Add-Content AGENTS.md
```
</CodeGroup>

## Checking the result

Although the file instructs the agent to run the check itself, it is also worth running it in CI.

```bash
pnpm dlx yummacss lint
```
